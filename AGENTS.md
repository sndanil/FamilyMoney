# Правила работы с репозиторием

## Git

- Никогда не выполнять `git commit` и `git push` без явной просьбы пользователя.
- Все изменения оставлять в рабочем дереве — коммитит и пушит только пользователь.
- Для проверки состояния можно использовать `git status`, `git diff`, `git log`
  и `git ls-remote`; эти команды ничего не меняют.

## Android

- После изменений, затрагивающих Android-приложение, обязательно собирать
  подписанный release APK:
  `dotnet build src/FamilyMoney.Android/FamilyMoney.Android.csproj -c Release -f net10.0-android`.
- Если к компьютеру подключено Android-устройство (`adb devices` показывает
  состояние `device`), устанавливать свежий APK поверх установленного:
  `adb install -r <com.familymoney.app-Signed.apk>`.
- После установки проверять `versionName`/`versionCode` и запускать приложение.
- Если подключённого устройства нет, сообщить об этом пользователю и не считать
  релиз обновлённым на телефоне.

## Интерфейс

- В диалогах кнопка подтверждения называется `OK` (латиницей, как в существующих
  диалогах) и стоит **слева** от «Отмена»: порядок слева направо — `OK`,
  «Отмена». Исключений нет.
- В выборе оформления счёта/категории вкладки называются по источнику:
  «Иконки» — векторные иконки, «Готовые» — поставляемые с приложением картинки,
  «Буква» — буквенный бейдж, «Свой файл» — загрузка.
- Эффект нажатия на кнопках и кликабельных заголовках — **расходящиеся волны**
  (`RippleLayer`), как в заголовке дня дневного списка. Стандартный эффект Fluent
  (подсветка `ContentPresenter`, сдвиг при нажатии) не используем: для кнопки
  с содержимым нужен свой `Template` и `RenderTransform="none"` в состоянии
  `:pressed`, а `RippleLayer` кладётся поверх содержимого в `Panel`.

## Скриншоты

- Снимать только на демонстрационной базе, не на реальных финансовых данных.
- Перед съёмкой выбирать период **«Год»**, для текущей демо-базы — **2026**,
  чтобы на экране было больше транзакций и скриншот был нагляднее.
- Обновлять файлы:
  - `resources/main.png` — десктоп, тёмная тема;
  - `resources/main_white.png` — десктоп, светлая тема;
  - `resources/mobile-main.png` — телефон, список по дням;
  - `resources/mobile-summary.png` — телефон, сводка по категориям;
  - `resources/mobile-tablet.png` — планшет, широкая раскладка.
- Мобильные скриншоты снимать в телефонном и планшетном размерах; интерфейс
  Android и компактного desktop общий.
