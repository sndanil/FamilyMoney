# Правила работы с репозиторием

## Git

- Никогда не выполнять `git commit` и `git push` без явной просьбы пользователя.
- Все изменения оставлять в рабочем дереве — коммитит и пушит только пользователь.
- Для проверки состояния можно использовать `git status`, `git diff`, `git log`
  и `git ls-remote`; эти команды ничего не меняют.

## Скриншоты

- Снимать только на демонстрационной базе, не на реальных финансовых данных.
- Перед съёмкой выбирать период **«Год»**, для текущей демо-базы — **2026**,
  чтобы на экране было больше транзакций и скриншот был нагляднее.
- Обновлять файлы:
  - `resources/main.png` — десктоп, тёмная тема;
  - `resources/main_white.png` — десктоп, светлая тема;
  - `resources/mobile-main.png` — телефон, список по дням;
  - `resources/mobile-summary.png` — телефон, сводка по категориям;
  - `resources/mobile-tablet.png` — планшет, широкая раскладка.
- Мобильные скриншоты снимать в телефонном и планшетном размерах; интерфейс
  Android и компактного desktop общий.
